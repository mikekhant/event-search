# Event Search

A daily 8:00am Pacific digest of events that match my interests, each with a sign-up link.

## What is in this repo

- `hub/index.html`: source of the Project Hub page (status, charter, plan, risks, decision log, budget).

More files arrive as the project moves through its phases: the interest profile and filter rules, the daily task prompt, and the handoff note.

## How it is maintained

The Chief of Staff chat commits and pushes after every change it makes. The daily runs do not push here; they append to the Event Digest doc in the Event Search project.
